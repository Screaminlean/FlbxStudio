# Changelog

All notable changes to this project are documented in this file.

## [0.9.0-beta] - 2026-10-24

This is the first tracked changelog entry.

### Added
- Program and User workspace navigation pages.
- User workspace page for loading and editing FLBX assets from user library locations.
- Settings controls for configuring Program and User library root paths.

### Changed
- FLBX parsing improved for catalog-based and inline/trailing asset layout variants.
- Home/User page list regions updated for independent scroll behavior.
- Save flow now defaults to the active FLBX filename.
- Save dialog now opens in the active FLBX folder when available.
- Navigation state handling now clears library selections and loaded assets when switching pages.
